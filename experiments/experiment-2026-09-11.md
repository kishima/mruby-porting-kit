# 実験記録: 一続きの作業での VM 移植（2026-09-11）

本の「移植の手順」章の主張（本書と本家のソースがあれば、一続きの作業で本家のテストを通す VM を移植できる）を測るための記録。
移植先の言語は本の本文には書かない。実例: [SabiRuby](https://github.com/kishima/sabiruby)。

## 条件

 * 対象: mruby 4.1.0-rc。コンパイラは本家の `mrbc`（VM のみを移植）
 * 作業者: AI（Claude）が本書の執筆に使ったのと同じセッション系列で、著者の指示のもと実装。本の本文は執筆時の知識として持っていたが、実装中は主に本家 `src/vm.c` を参照した
 * 作った範囲: RITE リーダ、実行ループ（119 命令のうち GETSV/SETSV、KEY_P/KEYEND/KARG が未実装）、組込みクラスのネイティブ実装、本家 `mrblib` のバイトコード埋め込み、命令予算のステップ実行。GC 無し、ホスト言語からの再入あり

 * 命令カバレッジ: 119 命令中 102 を実行（未実行: GETSV、SETSV、ARGARY、KEY_P、KEYEND、KARG、ASET、SYMBOL、METHOD、DEF、TCLASS、DEBUG、ERR、EXT1〜3、STOP。
   ARGARY と DEF が未実行なのは、対応する行が別の理由で先に落ちているため。要確認）

ファイル別の内訳は `mrbtest-2026-09-11.md`。

## 続き: 同じ本を仕様書として、テストを通しきるまで（同日）

一続きの作業の後、本の「移植の手順」章の材料を得るために続けた。結果 **805 / 833（97%）**、命令 105 / 119。
残り 28 の内訳: テスト用の C 補助コード（env.c、vformat.c、sysfail.c、ary_shared.c）が前提のもの 16、GC 前提のアリーナ検査 5、

本の章の「踏みやすい点」と `stages.md` に反映した。ファイル別の最終値は `mrbtest-final-2026-09-11.md`。

## つまずいた点（章の「踏みやすい点」の元）

本に書いてあったのに踏んだもの（5 件）: `ARYCAT` の nil 起点、クラス変数の起点（特異クラスを飛ばす）、`ensure` を通る `return`（break オブジェクト）、
`CALL` によるフレームの差し替え、`ARGARY` のレジスタ配置。

本に無くて困ったもの: メタクラスの連鎖をクラス生成時に作ること、`SEND` の第 3 operand の上位 4bit（キーワード引数の数）、`mrblib` が呼ぶ内部メソッドの一覧、
`Array#[]` が定数時間でなければ `each` が二乗になること、エラーメッセージの書式、検証イメージに gem が入っていること、テストドライバが足すネイティブ。

## 通らなかった主なもの

キーワード引数、`Module#prepend`、`Hash` のテストの大半（未分析）、本家のテスト用 C 拡張が前提のファイル（gc、env、vformat、sysfail）、Fiber。
